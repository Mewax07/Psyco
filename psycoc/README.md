# Psyco

**Psyco** is a programming language built around a simple idea:

> **If I want to understand it, I want to build it myself.**

The name *Psyco* comes from a personal feeling: the constant need to understand how things work by going back to their foundations and rebuilding them from scratch.

It is not meant to describe a mental illness. Instead, *Psyco* represents the mindset behind the project: curiosity pushed to the point where abstraction is no longer enough. Rather than simply using existing tools, Psyco is an attempt to understand and recreate the mechanisms behind them.

The language is designed with a strong focus on **control, explicitness, low-level programming and understanding how code actually works**.

Psyco currently provides functions, structures, enums, implementations, references, raw pointers, arrays, slices, pattern matching, control-flow constructs, function pointers, external functions and explicit type conversions.

The goal is not to hide the machine behind increasingly high-level abstractions.

The goal is to make the abstractions understandable.

# Psyco

**Psyco** est un langage de programmation construit autour d'une idée simple :

> **Si je veux comprendre quelque chose, je veux être capable de le construire moi-même.**

Le nom *Psyco* vient d'un ressenti personnel : cette volonté constante de comprendre comment les choses fonctionnent en revenant à leurs fondations et en les reconstruisant depuis zéro.

Il ne s'agit pas de faire référence à une maladie mentale. *Psyco* représente plutôt l'état d'esprit derrière le projet : une curiosité poussée jusqu'au point où utiliser une abstraction existante ne suffit plus. Plutôt que de simplement utiliser des outils déjà construits, Psyco cherche à comprendre et à reconstruire les mécanismes qui se trouvent derrière eux.

Le langage est conçu avec un fort accent sur le **contrôle, l'explicitation, la programmation bas niveau et la compréhension réelle de l'exécution du code**.

Psyco possède actuellement des fonctions, structures, énumérations, implémentations, références, pointeurs bruts, tableaux, slices, pattern matching, structures de contrôle, pointeurs de fonctions, fonctions externes et conversions de types explicites.

L'objectif n'est pas de cacher la machine derrière des abstractions toujours plus complexes.

L'objectif est de rendre ces abstractions compréhensibles.
